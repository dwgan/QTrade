# 因子研究与候选组合回测

本阶段把每日多因子排名从“候选生成器”扩展为可检验的研究闭环。研究入口只读取
`reports/factors/YYYY-MM-DD/rankings.parquet` 中已经归档的历史排名，不会用今天重新计算的
结果替代过去信号。

## 1. 因子有效性研究

```powershell
qtrade research factors `
  --start 2025-01-01 `
  --end 2025-12-31 `
  --horizon 20 `
  --quantiles 5
```

系统用信号日复权收盘价和第 20 个后续交易日的复权收盘价计算前瞻收益，并输出：

- 质量、价值、动量、低风险和综合得分的逐期 Spearman Rank IC；
- IC 均值、中位数、标准差、正值比例和 ICIR；
- 按综合得分从低到高的分组平均收益；
- 最高分组减最低分组的收益差，以及分组收益是否单调。

结果写入 `reports/research/factors/<start>_<end>/`，包含摘要、IC 明细和前瞻收益明细。
`end` 是信号截止日，不是行情截止日；评估最后一批信号时仍需准备足够的后续行情。

## 2. 候选组合回测

```powershell
qtrade backtest candidates `
  --start 2025-01-01 `
  --end 2025-12-31
```

回测规则：

- T 日收盘后读取归档排名，T+1 交易日收盘调仓；
- 按综合得分选取前 N 只股票，并限制单一行业最多持股数；
- 股票收益使用收盘价乘复权因子计算；
- 权重在两次调仓间随涨跌漂移；
- 按买卖权重变化的绝对值合计换手，并收取参数化单边成本；
- 使用配置的宽基指数作为基准。

结果写入 `reports/research/backtests/<start>_<end>/`，包含组合与基准的绩效摘要、
逐日净值和调仓明细。

## 3. 配置与边界

`config/base.yaml` 的 `research` 控制前瞻周期、分组数和最小横截面样本数；
`backtest` 控制初始资金、成本率、无风险利率、持股数、行业上限和基准代码。

交易成本是研究参数，不代表券商实际费率。当前版本已加入日线级滑点、涨跌停和停牌
延迟成交近似；整手、组合容量和盘中成交路径仍未模拟。详细口径见
[回测成交约束与稳健性](./11-回测成交约束与稳健性.md)。

只有实际归档的日期会成为研究信号。少量快照只能验证流程，不能支持可靠统计结论；
建议覆盖多个市场阶段后，再进行样本内、样本外和参数敏感性比较。
