# 本地操作界面

QTrade 本地操作界面把数据更新、市场分析、行业排名、候选筛选和每日观察整合为一个
浏览器工作台。它运行在个人电脑上，不需要部署服务器。

## 1. 启动

最简单的方式是双击项目根目录中的：

```text
start_qtrade.cmd
```

它会启动本地服务并自动打开浏览器。启动窗口需要保持打开；关闭窗口或按 `Ctrl+C` 会停止
QTrade。

也可以在项目目录打开 PowerShell：

```powershell
Set-Location D:\000-Workspace\QTrade
.\.venv\Scripts\python.exe -m qtrade ui
```

程序会自动打开：

```text
http://127.0.0.1:8765
```

如果不希望自动打开浏览器：

```powershell
.\.venv\Scripts\python.exe -m qtrade ui --no-browser
```

停止界面时回到 PowerShell，按 `Ctrl+C`。

## 2. 页面功能

### 日期

“已有报告日期”用于查看历史结果；日期输入框用于指定下一次运行的交易日。应选择已经
收盘且数据源已经更新的交易日。

### 更新数据并分析

联网调用数据源，并顺序执行：

1. 检查分析日之前是否已有财务快照；
2. 缺少时自动拉取最近五个季度的财务指标；
3. 更新当日数据；
4. 生成市场风险报告；
5. 生成行业与风格报告；
6. 生成多因子候选；
7. 生成自选股和影子组合观察；
8. 更新流水线报告和静态看板。

运行可能需要数分钟。任务在后台执行，页面会轮询状态。为避免重复请求，同一时间只允许
一个任务运行。

### 使用已有数据重算

不调用数据源，直接使用已经落盘的数据重新生成分析。适用于：

- 修改自选股后刷新观察结果；
- 调整分析配置后重新计算；
- 排查报告展示；
- 数据已经更新但报告生成中断。

本地重算会先检查日线、估值、股票基础信息和财务快照。缺少输入时不会启动一个注定失败的
任务，而会直接列出缺失的数据并提示先执行联网更新。

### 市场风险

展示市场状态、温度、趋势、宽度和风险健康度。风险建议用于确定研究与风险控制的优先级，
不是自动仓位指令。

### 行业与候选

行业表展示相对强弱和内部扩散度。候选表支持搜索和显示数量切换；点击候选股票后可查看
质量、价值、动量、低风险评分和入选理由。

### 自选股

每行填写一个 Tushare 股票代码，例如：

```text
600519.SH
000858.SZ
```

保存后选择“使用已有数据重算”，观察报告会显示自选股是否进入候选、是否完成排名及当前
排名。保存只修改 `config/base.yaml` 中的 `observation.watchlist_symbols`，不会改动其他
配置。

## 3. 策略回测

页面底部和左侧导航提供“策略回测”入口。第一次使用时保留默认日期即可：

1. 填写方案 ID、名称和研究假设；
2. 点击“创建方案并准备历史信号”；
3. 系统依次生成开发集、验证集和封存集的月末信号，固定每个分区的数据版本并冻结方案；
4. 方案显示“已冻结”后，先选择开发集运行；
5. 策略规则确定后运行验证集；
6. 只有决定不再根据结果修改策略时，才勾选确认并揭晓封存集。

历史信号准备可能需要数分钟。任务失败时展开日志，系统会显示停止在哪个分区以及底层命令
返回的原因；草稿方案可以在修复问题后继续准备。

回测结果区域展示组合与基准收益、年化收益、Sharpe、最大回撤、调仓次数、累计成本、
权益曲线，以及时间泄漏审计、信号版本和涨跌停受限成交统计。“月度持仓与调仓明细”
可以按信号日期查看当期最终持仓、新买入、继续持有和相对上期卖出的股票，并显示执行日期、
换手率、费用及受限买卖次数。

页面运行的是绑定冻结协议的正式回测，不允许任意修改协议日期。验证集遵守预先设置的试验
次数上限；封存集第一次运行必须显式确认，揭晓状态会永久记录。

当前成交模型在下一交易日收盘尝试成交，并处理无报价、涨跌停、延迟成交、费用和滑点；
尚未模拟 100 股整数手、最低佣金、成交容量和盘中价格路径。因此结果用于比较策略规则，
不等于可直接复制的实盘收益。

## 4. 安全边界

- 服务默认只监听 `127.0.0.1`；
- 页面不显示或返回 Token；
- Token 和自定义 API 地址仍从环境变量读取；
- 不连接券商，不发送订单；
- 候选结果用于缩小研究范围，不是确定性买卖建议。

不建议把 `--host` 改成局域网或公网地址。

## 5. 常见问题

### 页面显示凭据未配置

关闭当前 PowerShell，重新打开后再启动界面，确保用户环境变量已经进入新进程。

### 联网更新失败

打开页面中的运行日志，查看失败的数据集和错误信息。可以先使用已有数据重算，确认分析
模块是否正常。

### 日期没有报告

该日期尚未运行。若是已经收盘的交易日，点击“更新数据并分析”；非交易日不要运行日终
任务。未来日期和周末会在任务开始前被拒绝。

### 修改自选股后没有变化

保存自选股只更新配置，还需要点击“使用已有数据重算”生成新的观察报告。
