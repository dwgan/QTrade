# 数据字典

本文件描述第一阶段的标准数据集。原始层保留供应商字段；标准化层统一为小写字段名，并按主键去重和排序。

## 通用元数据

每个 Parquet 分区旁保存 `metadata.json`：

| 字段 | 含义 |
| --- | --- |
| `dataset` | 数据集名称 |
| `layer` | `raw` 或 `curated` |
| `provider` | 数据供应商 |
| `as_of_date` | 本次更新对应日期 |
| `fetched_at` | 实际获取时间 |
| `row_count` | 数据行数 |
| `columns` | 字段列表 |
| `request` | 不含凭据的请求参数 |

## `trade_calendar`

主键：`exchange, cal_date`

| 字段 | 含义 |
| --- | --- |
| `exchange` | 交易所 |
| `cal_date` | 日历日期，`YYYYMMDD` |
| `is_open` | 是否交易 |
| `pretrade_date` | 上一交易日 |

## `security_master`

主键：`ts_code, list_status`

| 字段 | 含义 |
| --- | --- |
| `ts_code` | 带交易所后缀的证券代码 |
| `symbol` | 证券数字代码 |
| `name` | 证券简称 |
| `area` | 地域 |
| `industry` | 供应商行业分类 |
| `market` | 主板、创业板、科创板等市场 |

| `list_status` | 上市状态 |
| `list_date` | 上市日期 |
| `delist_date` | 退市日期 |

## `security_names`

主键：`ts_code, name, start_date`

用于恢复历史 ST 和证券名称状态。

| 字段 | 含义 |
| --- | --- |
| `ts_code` | 证券代码 |
| `name` | 证券简称 |
| `start_date` | 名称生效日期 |
| `end_date` | 名称失效日期 |
| `ann_date` | 公告日期 |
| `change_reason` | 变更原因 |

## `daily_prices`

主键：`ts_code, trade_date`

| 字段 | 含义 |
| --- | --- |
| `ts_code` | 证券代码 |
| `trade_date` | 交易日期 |
| `open/high/low/close` | 不复权开高低收 |
| `pre_close` | 前收盘价 |
| `change` | 涨跌额 |
| `pct_chg` | 涨跌幅 |
| `vol` | 成交量，单位遵循供应商定义 |
| `amount` | 成交额，单位遵循供应商定义 |

分析前必须显式完成单位标准化，不能假设不同供应商单位一致。

## `adjust_factors`

主键：`ts_code, trade_date`

| 字段 | 含义 |
| --- | --- |
| `ts_code` | 证券代码 |
| `trade_date` | 交易日期 |
| `adj_factor` | 复权因子，必须大于零 |

底层同时保存不复权行情和复权因子，避免动态前复权基准变化导致历史序列漂移。

## `index_daily`

主键：`ts_code, trade_date`

字段与 `daily_prices` 基本一致，用于沪深 300、中证 500、中证 1000 等指数。

## `index_members`

主键：`index_code, con_code, trade_date`

| 字段 | 含义 |
| --- | --- |
| `index_code` | 指数代码 |
| `con_code` | 成分证券代码 |
| `trade_date` | 权重日期 |
| `weight` | 成分权重 |

指数成分不是每日完整快照。构建历史股票池时，系统会针对每个配置指数选择不晚于分析日的最近一期权重日期，并使用该日期的全部成分。任何一个配置指数缺少历史成分时，因子分析会失败。

## `financial_indicators`

主键：`ts_code, ann_date, end_date`

| 字段 | 含义 |
| --- | --- |
| `ann_date` | 实际公告日期 |
| `available_from` | 模型允许使用该披露的首日，当前保守设为公告后下一自然日 |
| `end_date` | 财务报告期 |
| `roe/roe_dt` | 净资产收益率及扣非净资产收益率 |
| `roic` | 投入资本回报率 |
| `grossprofit_margin` | 毛利率 |
| `netprofit_margin` | 净利率 |
| `ocfps` | 每股经营现金流 |
| `eps` | 每股收益 |
| `debt_to_assets` | 资产负债率 |

原始快照可以包含多个公告版本，但因子模型必须执行
`available_from <= as_of_date` 过滤。同一公告日的数据不能用于当日收盘信号。

## 通用时点字段

整理层数据统一增加：

| 字段 | 含义 |
| --- | --- |
| `available_from` | 该行数据允许进入模型的最早日期，格式为 `YYYYMMDD` |

因子排名中的 `available_from` 是价格、估值、财务和证券主数据各自可用日期的最大值。
正式回测要求所有历史排名都包含该字段。
