# 行业与风格分析

## 1. 目标

行业与风格模块用于判断市场上涨或下跌的内部结构：

- 哪些行业具有持续相对强势
- 强势行业内部是否有足够多股票参与
- 哪些行业只是少数股票推动
- 大盘、中盘和小盘风格谁占优

运行命令：

```powershell
qtrade analyze industry --date YYYY-MM-DD
```

输出：

```text
reports/industry/YYYY-MM-DD/
├── industry.json
└── industry.md
```

## 2. 数据要求

- 至少约 61 个交易日的 `daily_prices`
- 同期的 `index_daily`
- 分析日期或更早的 `security_master` 快照
- 股票基础信息中必须存在配置指定的行业字段

准备数据：

```powershell
qtrade data backfill --start 2026-01-01 --end 2026-07-24
qtrade data update --date 2026-07-24 --datasets security_master
qtrade analyze industry --date 2026-07-24
```

首版默认使用 Tushare 股票基础信息中的 `industry` 字段。该字段适合当前市场观察，但不能代替具有历史生效区间的标准行业分类。使用早于行业快照日期的历史回测时，系统不会向后借用未来快照。

## 3. 个股层指标

对分析日仍有行情且至少存在 61 个观测的股票计算：

- 5 日收益
- 20 日收益
- 60 日收益
- 是否位于 60 日均线上方
- 当日是否上涨
- 当日成交额相对近 20 日均值

行业聚合使用个股收益和成交活跃度的中位数，降低极端个股对行业结论的影响。

## 4. 行业指标

每个行业至少需要配置数量的有效股票，默认 5 只。

行业输出：

- 股票数量
- 5、20、60 日行业收益
- 相对沪深 300 的 20、60 日收益
- 位于 60 日均线上方的股票比例
- 当日上涨股票比例
- 成交活跃度
- 综合得分和排名
- 行业状态

## 5. 行业得分

综合得分使用行业间截面排名：

```text
行业得分 =
    20日相对收益排名 × 35%
  + 60日相对收益排名 × 25%
  + 60日均线上方比例 × 30%
  + 成交活跃度排名 × 10%
```

该得分衡量相对强弱和内部扩散度，不代表预期收益率。

## 6. 行业状态

首版状态规则：

| 状态 | 含义 |
| --- | --- |
| 趋势增强 | 中期强于基准、扩散充分，近期强度继续提高 |
| 强势延续 | 中期强于基准、扩散充分 |
| 高位分化 | 行业收益较强，但位于均线上方的股票不足 |
| 弱势修复 | 中期仍弱，但近期转正且扩散开始改善 |
| 趋势转弱 | 近期收益为负且内部扩散较弱 |
| 中性 | 暂不满足上述状态 |

这些标签用于解释，不直接生成交易指令。

## 7. 风格相对强弱

首版包含：

- 中证 500 相对沪深 300：中盘相对大盘
- 中证 1000 相对沪深 300：小盘相对大盘

分别计算 5、20、60 日相对收益，以 20 日和 60 日相对收益的均值判断当前领先方向：

- 高于 1%：分子指数占优
- 低于 -1%：分母指数占优
- 其余：均衡

阈值属于初始研究参数，后续需要结合历史切换频率验证。

## 8. 数据置信度

出现以下情况时降低置信度：

- 行业分类快照日期与分析日期不同
- 行业映射覆盖率低于 90%

如果缺少基准历史、行业字段或没有行业满足最小股票数，分析会直接失败并说明原因。

## 9. 当前限制

- Tushare `industry` 不是带历史生效区间的标准行业分类
- 行业收益使用等权个股中位数，不代表市值加权行业指数
- 暂未加入行业估值历史分位
- 暂未加入成长/价值风格指数
- 尚未验证行业状态的持续性和未来收益分布

后续若数据权限允许，应接入带历史区间的申万或中证行业分类，并对行业状态进行 Walk-forward 验证。
