# 市场分析 MVP

## 1. 目标

市场分析模块使用已经落盘的 A 股和指数日线数据，在指定交易日收盘后生成结构化市场状态。它回答“当前市场是否适合承担风险”，不预测下一交易日的具体涨跌。

运行命令：

```powershell
qtrade analyze market --date YYYY-MM-DD
```

输出：

```text
reports/market/YYYY-MM-DD/
├── market.json
└── market.md
```

JSON 用于后续看板和模型；Markdown 用于直接阅读。

## 2. 数据要求

- `daily_prices`：全市场股票日线
- `index_daily`：沪深 300、中证 500、中证 1000 日线
- 分析日期必须存在股票和指数数据
- 默认至少需要 120 个指数交易日
- 默认市场宽度至少覆盖 100 只股票

准备历史数据：

```powershell
qtrade data backfill --start 2025-01-01 --end 2026-07-24
```

回填命令只处理交易日并跳过已有分区，支持安全重跑。默认回填股票日线、复权因子和指数日线。

## 3. 指数趋势

每个指数计算：

- 20 日和 60 日收益
- 20、60、120、200 日均线
- 收盘价位于可用均线上方的比例
- 20 日年化波动率
- 相对过去 120 日高点的回撤

指数趋势得分为收盘价高于可用均线的比例。例如，四条均线全部位于收盘价下方时为 100 分。

综合趋势默认权重：

- 沪深 300：50%
- 中证 500：25%
- 中证 1000：25%

如果部分指数缺失，使用剩余指数重新归一权重，并在报告中保留实际指数明细。

## 4. 市场宽度

仅统计分析日期仍有行情的股票：

- 位于 20 日均线之上的比例
- 位于 60 日均线之上的比例
- 位于 120 日均线之上的比例
- 当日上涨比例
- 创 60 日新高比例
- 创 60 日新低比例

市场宽度得分使用：

| 指标 | 权重 |
| --- | ---: |
| 20 日均线上方比例 | 20% |
| 60 日均线上方比例 | 30% |
| 120 日均线上方比例 | 35% |
| 当日上涨比例 | 15% |

新高和新低比例作为解释指标展示，暂不直接进入首版评分。

## 5. 风险健康度

风险健康度越高，表示当前波动和回撤压力越小。

首版包含：

- 沪深 300 的 20 日年化波动率
- 沪深 300 相对过去 120 日高点的回撤

波动率在约 10% 以下接近满分，在约 40% 以上接近零分；回撤为零时接近满分，回撤达到约 25% 时接近零分。两项等权合成。

这些阈值属于第一版研究参数，必须通过后续历史验证确定是否需要调整。

## 6. 市场温度和状态

市场温度计算：

```text
市场温度 = 趋势 × 45% + 市场宽度 × 35% + 风险健康度 × 20%
```

状态划分：

| 温度 | 状态 |
| ---: | --- |
| 70 及以上 | 进攻 |
| 50 至 70 | 均衡 |
| 30 至 50 | 防守 |
| 30 以下 | 高风险 |

当前版本尚未加入状态切换迟滞。后续积累连续历史状态后，再评估确认天数和进入/退出阈值，避免在边界附近频繁切换。

## 7. 数据不足处理

出现以下情况时，状态设为 `insufficient_data`，市场温度为空：

- 缺少主要指数
- 主要指数历史短于配置要求
- 市场宽度覆盖股票数不足
- 股票或指数最新日期不是分析日期
- 无法计算市场宽度或风险健康度

报告会保留能够计算的分项指标和具体警告，但不输出伪精确综合分。

## 8. 当前限制

- 尚未使用历史指数成分限制市场宽度股票池
- 尚未处理行业和风格强弱
- 尚未做市场状态的 Walk-forward 验证
- 尚未加入状态迟滞
- 尚未考虑成交额和新高/新低对综合评分的额外影响
- 分析结果只用于研究和风险观察

下一步是用真实历史数据生成逐日市场状态序列，验证不同状态下的后续收益、回撤、切换频率和稳定性。
