# QTrade 文档

QTrade 是一个面向个人研究的 A 股日线决策辅助项目。系统在每日收盘后更新数据，分析市场状态、行业与风格变化，生成可解释的候选股票及风险提示。当前阶段不接入实盘交易，也不把系统输出视为直接买卖指令。

## 当前已确定的决策

- 市场：A 股
- 数据频率：日线
- 使用者：个人研究
- 产品定位：市场分析和操作参考
- 运行时间：交易日收盘后
- 首版股票池：沪深 300 与中证 500 的历史成分股
- 首版策略：市场环境模型 + 行业强弱 + 质量/价值/动量/低风险多因子
- 数据源：优先使用 Tushare Pro，通过适配器隔离具体供应商
- 输出形式：先生成 Markdown/HTML 报告，后续增加本地 Streamlit 看板
- 交易范围：暂不自动下单，不接入量化交易平台

## 设计原则

1. **时间一致**：历史分析只能使用当时已经公开的数据。
2. **结果可解释**：每项评分都能追溯到原始指标和计算方法。
3. **研究可复现**：固定数据快照、配置、代码版本和运行参数。
4. **回测要保守**：显式处理费用、停牌、涨跌停和下一交易日成交。
5. **报告不越界**：输出关注理由、风险和失效条件，不包装成确定性预测。
6. **先闭环后扩展**：先完成数据—分析—回测—报告闭环，再考虑机器学习和实时数据。
