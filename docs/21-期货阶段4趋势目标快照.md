# 期货阶段 4：趋势目标快照

## 1. 当前范围

阶段 4 第一里程碑只生成时点一致、不可变的实际合约目标手数快照，不运行或发布真实收益。
目标快照可作为阶段 3 回测输入，但不得绕过历史涨跌停、保证金和成交门禁。

## 2. 冻结协议

首版 `FuturesTrendProtocol` 固定为：

- 趋势周期：20、60、120 个交易日；
- 周期权重：各 `1/3`，对每个周期收益取符号后加权，信号范围为 `[-1, 1]`；
- 波动率：截至 `T` 日最近 40 个日收益的样本标准差；
- 年化交易日：252；
- 组合目标年化波动率：8%；
- 单品种日风险预算上限：组合日风险预算的 10%；
- 单板块绝对日风险上限：组合日风险预算的 30%；
- 初始保证金占用上限：账户权益的 25%；
- 压力保证金占用上限：历史方向保证金率上调 50% 后不超过账户权益的 50%；
- 仓位变化缓冲：同方向非零目标变化不超过旧仓 10%，且至少在 1 手以内时保持旧手数；
- 目标必须为整数手，不允许小数手。

协议内容生成稳定 `protocol_id`。服务 CLI 不提供覆盖这些参数的选项，参数变更必须修改协议、
增加邻域测试并产生新的协议 ID。

单品种基础日风险预算：

```text
账户权益 × 8% ÷ sqrt(252) × 10%
```

实际分配日风险为基础预算乘以信号绝对强度。一手日风险为：

```text
T 日目标实际合约结算价 × 合约乘数 × 40 日估计日波动率
```

目标手数向下取整。一手风险超过实际分配预算时输出 `insufficient_capital` 和零手，不用小数
手美化结果；信号为零时输出 `flat_signal`。

首版组合风险采用各品种绝对日风险求和，并依次应用板块、组合、初始保证金和压力保证金
上限。缩减使用确定性的比例缩放与最大余数回填，只能减少整手目标，不能改变多空方向。
当前不给予样本相关性分散化优惠，避免使用不稳定相关矩阵放大仓位。快照同时保留
`unconstrained_signed_lots`、最终手数和每项 `limit_reasons`。

缓冲位于原始目标和组合风险分配之间。开仓、清仓和反向不缓冲；保留旧手数会超过当日
单品种风险预算时也不缓冲。缓冲后的目标必须重新通过板块、组合、初始保证金和压力保证金
四层限制。快照记录 `buffered_signed_lots`、`buffer_applied` 和 `buffer_reason`。

## 3. 时点与谱系门禁

- 连续序列只读取 `T` 日及以前的数据；
- 品种必须在阶段 2 的 `T` 日动态品种池中合格；
- 实际目标合约必须匹配阶段 2 的 `T` 决策、`T+1` 生效换月记录；
- 目标合约结算价来自阶段 2 manifest 声明的 `T` 日标准化行情分区；
- 合约乘数来自阶段 2 manifest 声明的时点可见合约主数据分区；
- 多空保证金率来自精确 `T` 日标准化结算参数分区，按目标方向选择；
- 品种板块来自代码冻结、带哈希版本的注册表，未知品种直接阻断；
- 阶段 2 schema v2 在 manifest 中保存所有研究 Parquet 的 SHA256 和大小；
- 源分区或研究产物缺失、重复或被改写时，在创建目标目录前拒绝构建；
- 动态品种池为空是合法结果，输出具有固定 schema 的零行目标表。
- 后续日快照只接受 `previous_signal_build_id`，不接受调用者手填旧仓；
- 上一快照必须使用相同阶段 2 构建和协议，且其生效日必须等于当前信号日；
- 每个 `targets.parquet` 的 SHA256 和大小写入 signal manifest，链式读取前必须核验；
- 上一日非零持仓品种退池时，沿用上一实际合约输出零手 `universe_exit` 平仓目标。

修改 `T+1` 连续价格不会改变 `T` 目标。目标输入、阶段 2 manifest、研究产物、源分区、协议和
权益共同进入内容寻址构建 ID。

## 4. CLI 与产物

冻结输入示例：

```json
{
  "research_build_id": "<phase-2-schema-v2-build-id>",
  "signal_date": "2026-07-30",
  "eligible_date": "2026-07-31",
  "equity": 1000000,
  "previous_signal_build_id": "<previous-signal-build-id-or-omit-for-first-day>"
}
```

执行：

```powershell
qtrade futures trend --input runtime/futures-trend.json
```

不可变目录：

```text
data/curated/futures/signals/build_id=<build-id>/
├── manifest.json
└── targets.parquet
```

质量报告位于 `reports/futures/signals/<build-id>/report.md`。相同输入直接复用；任何输入、协议或
上游内容变化都会产生新构建 ID。signal schema v3 支持按交易日串联不可变快照；首日省略
`previous_signal_build_id`，之后每一天引用上一日构建。
