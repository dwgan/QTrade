# 回测成交约束与稳健性

本阶段在候选组合回测中加入保守的 A 股收盘成交约束，并把单次全样本绩效扩展为
样本拆分和成本敏感性结果。

## 1. 成交状态

回测仍使用 T 日收盘信号，并从 T+1 收盘开始尝试调仓：

- 股票在执行日没有日线行情时，视为停牌或无有效报价，不能买卖；
- 收盘价达到涨停价时，不执行买入；
- 收盘价达到跌停价时，不执行卖出；
- 未完成的目标仓位在后续交易日继续尝试；
- 受限卖出继续保留原持仓，受限买入对应资金保持现金；
- 新信号到来时，用最新目标替换尚未完成的旧目标。

这是基于日线数据的保守近似。它无法还原盘中打开涨跌停后曾经可成交的时段，也不能
判断排队成交概率。

涨跌停价格来自 `stock_limit` 数据集。若回测区间没有该数据，系统仍可运行，但会在报告
中说明涨跌停约束未启用。

新版默认回填集合已经包含该数据；对旧数据目录可补充执行：

```powershell
qtrade data backfill `
  --start 2020-01-01 `
  --end 2025-12-31 `
  --datasets stock_limit
```

## 2. 成本和滑点

每次实际发生的买卖权重变化形成换手：

```text
turnover = Σ |new_weight - old_weight|
```

回测分别计算交易费用和滑点：

```text
transaction_cost = equity × turnover × transaction_cost_rate
slippage_cost    = equity × turnover × slippage_rate
```

全仓买入的换手为 1；完整卖出旧组合再买入新组合的换手接近 2。

## 3. 延迟成交审计

`rebalances.parquet` 对每次成交尝试记录：

- 信号日和实际尝试日；
- `completed` 或 `partial` 状态；
- 实际换手、交易费用和滑点；
- 被限制的买入、卖出数量；
- 成交后权益和持仓数。

摘要同时给出累计受限买卖次数和发生延迟重试的交易日数。逐日净值文件新增现金权重，
便于识别因无法买入而产生的空仓。

## 4. 样本内和样本外

可以显式指定样本外开始日：

```powershell
qtrade backtest candidates `
  --start 2020-01-01 `
  --end 2025-12-31 `
  --split-date 2024-01-01
```

未指定时，系统按 `backtest.sample_split_ratio` 将前 70% 交易日作为样本内，后 30%
作为样本外。报告分别计算组合和基准绩效。这个切分只负责展示隔离，不允许根据样本外
结果反向选择参数。

## 5. 成本敏感性

`backtest.cost_sensitivity_multipliers` 默认使用 0、1、2 倍交易成本，并保持滑点不变。
报告列出各场景的总收益和最大回撤，用来判断策略是否依赖过低的成本假设。

## 6. 当前边界

当前仍使用权重级组合模型，尚未模拟：

- 100 股整手和零股卖出；
- 佣金最低收费、印花税和过户费的逐笔差异；
- 成交量参与率和策略容量；
- 开盘、VWAP 或盘中订单路径；
- 退市整理期等特殊交易规则。

这些约束需要升级为持股数量、现金和订单级撮合模型后再加入。
