# 每日观察与影子组合

每日观察把多因子输出转换为便于收盘后复盘的变化报告，但不发送订单，也不产生直接的
买卖指令。

## 1. 配置自选股

在 `config/base.yaml` 中填写 Tushare 股票代码：

```yaml
observation:
  watchlist_symbols:
    - 600519.SH
    - 000858.SZ
  candidate_count: 20
  rank_mover_count: 10
  shadow_lookback_calendar_days: 365
```

系统会自动去除空值和重复代码，并统一转换为大写。

## 2. 生成日报

完成当日数据更新和因子分析后运行：

```powershell
qtrade analyze factors --date 2026-07-24
qtrade observe daily --date 2026-07-24
```

报告写入：

```text
reports/observations/2026-07-24/
  observation.json
  observation.md
  shadow_equity_curve.parquet
  shadow_rebalances.parquet
```

## 3. 候选变化

系统把当日归档排名与最近一个更早的归档排名比较，输出：

- 新进入前 N 名的股票；
- 退出前 N 名的股票；
- 排名变化绝对值最大的股票；
- 当前排名、前次排名和变化方向。

“前次”表示最近一次实际存在的因子快照，不保证是前一个自然日或交易日。报告会明确
显示两个快照日期。

首次运行没有前次快照时，不会把所有候选错误标记为新进入，而是提示暂时无法比较。

## 4. 自选股状态

每只自选股会标记为：

- `candidate`：处于配置的候选排名范围；
- `ranked`：进入有效股票池并完成排名，但不在候选范围；
- `not_ranked`：不在当日完整排名中。

`not_ranked` 不等于看空。它可能意味着停牌、ST、上市时间不足、流动性不足、财务或
估值数据缺失，以及其他风险过滤条件。需要结合当日因子报告的过滤统计判断。

## 5. 影子组合

影子组合不维护一份可手工修改的持仓状态。每次运行都会读取观察窗口内的不可变因子
快照，重新执行候选组合回测，因此相同数据、配置和代码版本应得到相同结果。

它复用正式回测口径：

- T 日收盘信号，T+1 收盘尝试执行；
- 停牌、涨停买入和跌停卖出限制；
- 未成交目标逐日重试；
- 交易费用和滑点；
- 行业数量上限和候选持股数。

当日刚生成的候选信号最早在下一交易日才能进入影子组合，因此“当前候选”与“影子
持仓”不必相同。这是时间一致性的预期结果。

## 6. 使用边界

观察日报用于回答“今天发生了什么变化、哪些股票值得继续研究、历史信号组合表现
如何”。它不代替公司公告核查、基本面判断、仓位约束和个人风险决策。
