# 项目范围与目标

## 1. 项目定位

QTrade 是一个 A 股日线研究和决策辅助系统。它不代替用户做投资决策，而是把分散的行情、财务和风险信息转化为可复核的分析结果。

系统每天收盘后回答以下问题：

1. 当前市场处于进攻、均衡、防守还是高风险状态？
2. 大盘、小盘、成长、价值等风格谁更强？
3. 哪些行业正在持续走强，哪些只是短期异动？
4. 哪些股票在质量、价值、动量和风险维度上更值得研究？
5. 当前判断面临哪些风险，什么变化会使判断失效？

## 2. 目标用户和使用方式

目标用户为个人投资研究者，典型流程如下：

1. 交易日收盘后运行数据更新和分析任务。
2. 阅读市场总览，判断当前适合承担的风险程度。
3. 查看行业趋势和候选股票。
4. 对自选股进行进一步分析。
5. 结合个人研究作出独立决策。
6. 记录观察结果，定期复盘系统是否真正提供了参考价值。

系统输出属于研究信息，不是保证收益的投资建议。

## 3. MVP 范围

### 3.1 首版包含

- A 股交易日历和证券基础信息
- 股票、指数日线行情及复权因子
- 沪深 300、中证 500 等主要指数分析
- 市场趋势、宽度、波动和回撤分析
- 申万或中证行业强弱分析
- 质量、价值、动量、低风险多因子排名
- ST、停牌、涨跌停、流动性等风险过滤
- 历史回测和因子分组测试
- 自选股和候选股持续跟踪
- 每日 Markdown/HTML 报告
- 本地可视化看板

### 3.2 首版不包含

- 自动实盘交易
- 券商账户和订单接口
- 分钟线、Tick 和盘口数据
- 高频或日内策略
- 融资融券、期权和杠杆交易
- 大模型直接预测个股涨跌
- 新闻情绪驱动交易
- 多用户、权限和云端 SaaS
- 移动端应用

## 4. 产品输出

### 4.1 每日市场报告

至少包括：

- 数据日期、完整性和更新时间
- 市场状态与市场温度
- 主要指数趋势
- 市场宽度、波动率和回撤
- 风格相对强弱
- 行业强弱及持续性
- 候选股票及分项得分
- 自选股变化
- 风险提示和判断失效条件

### 4.2 每周研究报告

至少包括：

- 市场状态一周变化
- 行业排名及排名变化
- 新进入和退出观察池的股票
- 模拟观察组合表现
- 因子近期表现
- 本周异常数据和模型告警

### 4.3 个股分析卡片

单只股票应展示：

- 所属行业和可交易状态
- 质量、价值、动量、低风险得分
- 综合得分及历史排名
- 相对指数、行业的强弱
- 估值历史位置
- 盈利、现金流和负债变化
- 近期波动和最大回撤
- 入选原因、主要风险和退出条件

## 5. 默认研究参数

首版按以下假设推进，参数均应配置化：

- 风险偏好：中等
- 研究周期：2 周至 3 个月
- 数据更新：每个交易日收盘后
- 市场分析：每日更新
- 候选排名：每日更新
- 正式观察池：每周调整
- 股票池：沪深 300 + 中证 500 历史成分股
- 首版暂时排除金融行业，后续为其设计专用财务因子
- 候选数量：20 至 30 只
- 模拟观察组合：20 只左右、单只等权或受限等权

## 6. MVP 验收标准

完成以下条件后视为 MVP 可用：

- 一条命令完成增量数据更新
- 一条命令生成指定日期的完整报告
- 任一历史报告能够通过相同数据和配置复现
- 所有评分能够追溯到具体因子值
- 数据缺失或延迟时报告会明确告警
- 回测不使用未来财务数据或当前成分股替代历史成分股
- 回测处理停牌、涨跌停、费用和下一交易日成交
- 样本内、样本外和滚动验证结果可同时查看
- 系统能连续记录至少 8 至 12 周真实盘后信号
- 历史信号和报告生成后不可被后续数据静默覆盖
