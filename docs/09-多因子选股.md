# 多因子选股

## 1. 目标

多因子模块从可交易股票中生成一个可解释的研究候选池。它综合：

- 财务质量
- 价值
- 中期动量
- 低风险

系统同时输出完整排名和过滤原因，不把候选结果包装成直接买入建议。

## 2. 数据准备

至少需要：

- 约 121 个交易日的 `daily_prices`
- 同期 `adjust_factors`
- 分析日 `daily_basic`
- 多个季度的 `financial_indicators`
- 分析日或更早的 `security_master`
- 分析日 `stock_limit`，缺失时降低置信度

示例：

```powershell
qtrade data backfill --start 2026-01-01 --end 2026-07-24

qtrade data financials `
  --date 2026-07-24 `
  --periods 20250331,20250630,20250930,20251231,20260331

qtrade data update `
  --date 2026-07-24 `
  --datasets security_master,daily_basic,stock_limit

qtrade analyze factors --date 2026-07-24
```

财务快照命令使用全市场季度接口。普通财务接口只能逐只股票读取历史，全市场 `fina_indicator_vip` 需要更高积分权限，具体以 [Tushare 财务指标文档](https://tushare.pro/document/2?doc_id=79) 为准。

## 3. 时间一致性

财务数据按以下顺序处理：

1. 保留 `ann_date <= 分析日期` 的记录。
2. 每只股票按公告日期和报告期排序。
3. 只使用分析日当时最新的已公告财务指标。
4. 后续公告和修订不得进入过去日期的评分。

每日估值、证券基础信息也只能读取分析日或更早的本地快照。

## 4. 初始过滤

默认排除：

- ST、`*ST` 和名称包含退市风险标记的股票
- 上市不足约一年
- 缺少估值或财务数据
- 近 20 日成交额处于股票池底部 20%
- 分析日处于涨停或跌停
- 银行、保险、证券和多元金融
- 不足 121 个有效价格观测

金融行业暂时排除，是因为普通企业的 ROE、负债率和现金流指标不能直接套用于金融机构。

## 5. 原始因子

### 5.1 质量

- 扣非 ROE，缺失时使用 ROE
- ROIC
- 每股经营现金流与每股收益的匹配程度
- 净利率
- 负资产负债率

### 5.2 价值

- 盈利收益率 `1 / PE_TTM`
- 账面收益率 `1 / PB`
- 销售收益率 `1 / PS_TTM`
- 滚动股息率

负数或无意义的估值倒数不直接使用，由截面缺失处理补齐。

### 5.3 动量

使用不复权收盘价与复权因子构造一致的后复权收益：

- 20 日收益
- 跳过最近 5 日的 60 日收益
- 跳过最近 5 日的 120 日收益

跳过最近 5 日用于降低短期过热对中期动量的影响。

### 5.4 低风险

- 负 60 日年化波动率
- 相对过去 120 日高点的回撤

波动越低、回撤越小，低风险得分越高。

## 6. 截面处理

每个原始因子依次执行：

1. 行业内中位数补缺，再使用全市场中位数兜底。
2. 2.5% 和 97.5% 分位缩尾。
3. 减去行业均值。
4. 对数总市值线性回归并取残差。
5. 对残差进行全市场标准化。

该流程降低行业和市值暴露，但不能完全替代正式风险模型。

## 7. 合成权重

默认：

| 因子组 | 权重 |
| --- | ---: |
| 质量 | 35% |
| 动量 | 30% |
| 价值 | 20% |
| 低风险 | 15% |

综合标准分转换为 0 至 100 的截面百分位。权重属于研究假设，进入正式使用前必须做分组回测和参数邻域测试。

## 8. 候选池

- 默认输出 30 只
- 单行业最多 5 只
- 保留候选股在全市场的原始排名
- 展示四组得分
- 展示得分最高的两项入选理由
- 财务公告距分析日超过 200 天时增加风险标记

输出：

```text
reports/factors/YYYY-MM-DD/
├── factors.json
├── factors.md
└── rankings.parquet
```

`rankings.parquet` 保存全部合格股票，而不只是最终候选。

## 9. 当前限制

- 股票池当前使用所有满足过滤条件的本地 A 股，不是严格历史沪深 300 + 中证 500
- 行业分类暂时使用证券基础信息中的当前行业字段
- 财务质量使用供应商现成指标，尚未从三张报表独立重算
- 尚未进行因子 IC、分组收益和样本外验证
- 尚未加入候选缓冲区和周度观察组合

下一阶段应实现因子研究与候选组合回测，再决定这些因子和权重能否进入日常研究报告。
